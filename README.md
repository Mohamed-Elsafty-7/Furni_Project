# Furni — Furniture Store Website

Furni is a multi-page furniture-store website concept for presenting products and exploring a shopping-style interface.

## Live Demo

[Visit Furni](https://mohamed-elsafty-7.github.io/Furni_Project/)

## Features

- Home page introducing the furniture store.
- Shop page for presenting furniture products.
- About Us and Services pages.
- Blog and Contact pages.
- Cart page layout.
- Shared navigation across the main pages.
- Responsive layout components from Bootstrap.

## Built With

- HTML5
- CSS3
- Bootstrap
- Font Awesome

## Run Locally

```bash
git clone https://github.com/Mohamed-Elsafty-7/Furni_Project.git
```

Open `index.html` in your browser.

## What I Practiced

- Structuring a multi-page website.
- Using Bootstrap components and utility classes.
- Creating consistent navigation between pages.
- Organizing shared styles and local assets.
- Designing a shopping-oriented user interface.

## Current Limitations

This repository contains a front-end store interface. The reviewed files do not establish a connected back-end or complete cart-management workflow, so cart controls should be treated as interface elements.

## Possible Improvements

- Implement interactive cart management.
- Add product filtering and sorting.
- Connect products and orders to a back-end.
- Improve accessibility and mobile usability.
